Bookish — test du scanner (caméra)

Ouvre le scanner réel dans l'application et vérifie le flux caméra, le moteur de décodage et le décodeur de secours.
En cours…
Ce test nécessite que le navigateur ait la permission caméra : le pilote tools/cdp-run.ps1 l'accorde avec -GrantCamera. Sur les postes où le BarcodeDetector natif n'existe pas (Windows, Linux), le décodeur de secours jsQR est attendu ; sur Android/Chrome le scan natif est attendu.
